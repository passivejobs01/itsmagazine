# 미니PC를 게임기로 — 설치 가이드

미니PC에 **Bazzite**(게이밍 리눅스)를 올려서 스팀 게임 · 레트로 게임 · **원격 플레이**까지
쓰는 구성입니다. 영상에서 짧게 넘어간 **커맨드와 순서**를 여기 적어둡니다.

## 영상의 나머지 단계

커맨드가 필요한 부분이 없어서 문서로 따로 만들지 않았습니다. 받는 곳만 적어둡니다.

| 단계 | 어디서 |
|---|---|
| **Bazzite 설치** | [bazzite.gg](https://bazzite.gg/) → Desktop → 그래픽카드 선택 → KDE → [Rufus](https://rufus.ie/)로 USB 굽기 → 부팅 후 **Install to Hard Drive** |
| **Steam** | 설치 후 아이콘만 누르면 자동으로 설치됩니다 (QR 코드로 로그인) |
| **레트로 게임** | 소프트웨어 센터(Discover)에서 **RetroDECK** 설치 → 홈 폴더의 `retrodeck` 에 BIOS·ROM 복사 |
| **Steam에 등록** | Steam → 라이브러리 → **게임 추가 → 비 Steam 게임 추가**로 RetroDECK 등록 |

> ⚠️ **윈도우를 지우기 전에 드라이버를 백업**해두세요. 제조사 홈페이지에 드라이버가
> 올라와 있으면 괜찮지만, 없는 제품도 많습니다. 멀티부팅으로 윈도우를 남겨둘 수도 있습니다.

> ⚠️ BIOS·ROM 파일은 **저작권을 지켜** 사용하세요.

## 검증 환경

여기 적힌 내용은 아래 환경에서 **직접 확인**했습니다.

| 항목 | 값 |
|---|---|
| 기기 | ACEMAGIC M1 (미니PC) |
| CPU·GPU | AMD Ryzen 7 7735HS · **Radeon 680M** 내장그래픽 |
| 메모리 | 16GB (온보드 — 교체 불가) |
| OS | Bazzite 44.20261012 (KDE Plasma · Wayland) |
| 네트워크 | 호스트 유선 기가비트 · 클라이언트 Wi-Fi 5GHz |
